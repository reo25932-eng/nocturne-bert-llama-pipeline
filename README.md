# nocturne-bert-llama-pipeline
東北大BERTによるノクターン小説のヒット予測と、Llama-3による「最適化バフ」第1話自動生成パイプライン（※コードはエラーの卵嚢に塗れています）
🚀 本プロジェクトの成果
市場の学習: 東北大学の日本語BERT（bert-base-japanese-v3）をノクターンデータでファインチューニング。

検証された覇権プロット: マブラヴ風×男女比崩壊×機械学習バフ（Dropout/正則化）プロットを投入。

AIの神託: 自作BERT検算器により、大ヒット確率 92.76%（過学習の可能性アリ）を記録。

デバッグの軌跡: fugashi や unidic_lite の未インストールエラー、KaggleのInternet Offによる通信エラーなどの卵嚢をすべて駆逐。
